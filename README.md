# Вечный букет (flora.faux)

Лендинг-визитка: один файл `index.html` + фото в `img/`. Без сборки, ~12 КБ кода и ~350 КБ фото.

- Номер WhatsApp — константа `WHATSAPP` в конце `index.html` (только цифры, например `79991234567`)
- Букеты — массив `bouquets` там же
- Запуск локально: `python3 -m http.server 8000`
